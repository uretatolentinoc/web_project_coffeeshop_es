# Triple Espresso

Lading page de una cafeteria.
Es una LadingPage para una cafeteria el cual tiene una seccion de reservacion de mesas con el uso de codigos de Formulario <form> y el uso de botones con el codigo <button> para confirmar esa reserva, ambos elemntos con ayuda de los elementos <label> e <input>. Este ultimo elemento <input> con el tipo TYPE=checkbox sirve para marcar casillas de aceptacion.
Esta seccion de reservacion tambien viene redirigida desde la ladingpage principal con los enlaces para #reservation y #contacts.
al redirigirnos internamente en la ladingpage con el enlace #contacts, este nos ubica en el pie de pagina <footer> el cual contiene toda la informacion de contaactos, dentro de esta parte con ka ayuda nuevamente de enlaces <a> redirgimos las paginas web de facebook e intagram a traves de nuestro LadingPage.
Cada uno de estos elementos posee su respectiva clase particular o general, acorde a lo que se requiere, para desendecia o caracteristicas particulares, los cuales cumples con las buenas practicas aprendidas en el Sprint3, usando las metodologias CSS y tipos de selectores correspondientes.
